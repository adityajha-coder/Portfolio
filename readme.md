Portfolio Website

A personal portfolio website built with HTML, CSS (Tailwind), and JavaScript, featuring a 3D background using Three.js.

Structure

index.html: Main HTML structure.

css/style.css: Custom styles and animations (moved into css directory).

js/main.js: Entry point that imports data and component renderers to populate the page. Render logic has been split into multiple modules under `js/components`.

three-bg.js: Three.js 3D background animation scene.
